# data-processors

Lambdas that insert/update blockchain data (Postgres, DynamoDB, Neo4j, ETHscan). Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/data-processors-archive`.

p2pify RPCs → public BSC seed. VPC/SG ids and AWS account selectors placeholdered. `cdk.context.json` dropped. **Rotate those p2pify keys** if still live.

No contract deployments recorded in this repo.

## What was built

CDK Lambdas for blocks/txs/logs into Aurora, DynamoDB token/pair updaters, Neo4j, ETHscan wallet/staking inserters, trade calculator.

## Qué se construyó

Procesadores de datos on-chain. RPCs de pago sustituidos; IDs de AWS placeholdered.
